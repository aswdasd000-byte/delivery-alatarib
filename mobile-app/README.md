# ديليفري الأتارب — تطبيق الهاتف

بداية تطبيق React Native مبني على Expo وTypeScript، منفصل عن صفحات الويب الحالية حتى لا نكسر النسخة المنشورة.

## التشغيل

1. ثبّت Node.js LTS ثم نفّذ من هذا المجلد: `npm install`.
2. انسخ `.env.example` إلى `.env` وضع رابط Supabase ومفتاح publishable.
3. نفّذ `npx expo start` وافتح المشروع عبر Expo Go أو محاكي Android.

## المرحلة الأولى

- هيكل تطبيق Expo/TypeScript.
- اتصال Supabase باستخدام publishable key فقط.
- واجهة عربية RTL أولية لعرض المتاجر والمنتجات.

## ما لم يُنجز بعد

تطبيقات الإنتاج للعميل والمندوب، مصادقة وأدوار آمنة، تتبع GPS بالخلفية، حساب المسافة الفعلية، الدفع الإلكتروني، الإشعارات، التقارير، اختبارات الأجهزة والنشر على المتاجر. لا تعتبر هذه النسخة جاهزة للإطلاق التجاري قبل تنفيذها واختبارها.
