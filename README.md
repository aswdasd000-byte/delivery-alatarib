# ديليفري الأتارب

تطبيق ويب تقدمي (PWA) باللغة العربية واتجاه RTL لخدمة طلبات التوصيل في الأتارب والمناطق القريبة.

## مكونات المشروع
- `index.html`: واجهة الزبون وتقديم الطلبات وتتبعها.
- `restaurant.html`: لوحة المطعم لإدارة الطلبات.
- `driver.html`: لوحة السائق لاستلام الطلبات وتحديث حالتها.
- `admin.html`: لوحة المدير لإدارة الطلبات والمتاجر والسائقين.
- `service-worker.js` و`manifest.json`: دعم تثبيت التطبيق وإشعارات Push.

## البنية التقنية
- الواجهة مستضافة على GitHub Pages.
- قاعدة البيانات وتسجيل الدخول وواجهات RPC والإشعارات تعتمد على Supabase.
- لا تُشغّل الصفحات بفتح ملفات HTML محلياً؛ استخدم رابط الاستضافة حتى تعمل المسارات وService Worker بشكل صحيح.

## حالات التشغيل والقيود المعروفة
- التطبيق مرتبط بقاعدة بيانات مشتركة، وليس تخزيناً محلياً فقط.
- سجل طلبات الزبون يعتمد حالياً على بيانات المتصفح المحلية مع إمكانية تتبع الطلب برقم الطلب ورقم الهاتف؛ لم تُنفذ بعد استعادة آمنة لسجل الزبون بين الأجهزة.
- إشعارات Push تحتاج السماح بها من المتصفح وتفعيل الاشتراك لكل دور/جهاز. نجاح إرسال المزود لا يضمن أن المستخدم شاهد الإشعار.
- صور المتاجر والمنتجات غير مكتملة، ويجب رفعها وربطها قبل الإطلاق التجاري.
- لم يُعتمد بعد اختبار قبول نهائي شامل من الزبون إلى المطعم فالسائق فالمدير باستخدام حسابات حقيقية.

## تنبيهات أمنية وتشغيلية
- لا تضع مفاتيح Supabase السرية أو مفاتيح الخدمة أو أسرار Push في ملفات الواجهة أو مستودع GitHub.
- صلاحيات قاعدة البيانات وسياسات RLS ودوال RPC جزء أساسي من حماية الطلبات.
- اختبر أي تغيير على نسخة تجريبية قبل نشره على المستخدمين.
- هذا المشروع ما زال قيد التطوير ولا ينبغي اعتباره جاهزاً لإطلاق تجاري واسع قبل إكمال اختبارات الأمان والتشغيل.
