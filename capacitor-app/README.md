# ديليفري الأتارب — Capacitor Android

هذا المشروع يضيف غلاف Android واحداً فوق موقع التطبيق الحالي، ويحافظ على صفحات الزبون والمطعم والسائق والمدير في النسخة المنشورة. لا ينسخ قاعدة البيانات ولا يغيّر Supabase.

## بناء APK تجريبي

يُبنى تلقائياً عبر GitHub Actions عند تشغيل workflow باسم **Build Android APK** من تبويب Actions. ينتج APK تجريبي غير موقّع للنشر التجاري (debug APK) ويمكن تنزيله من Artifacts.

## ملاحظات مهمة

- التطبيق يحمّل النسخة المنشورة من GitHub Pages؛ يلزم اتصال إنترنت.
- هذا أول غلاف Android فقط، وليس بعدُ تكاملاً كاملاً مع ميزات Android الأصلية.
- إشعارات الويب الحالية قد لا تعمل داخل WebView مثل عملها في Chrome. يلزم تنفيذ وربط إشعارات Push أصلية واختبارها على هاتف Android قبل الاعتماد.
- الموقع الحالي يبقى متاحاً كما هو، ومجلد Expo السابق `mobile-app` لم يتم تعديله.
- لا تضع مفاتيح Supabase السرية أو service_role في ملفات التطبيق. يستخدم الموقع إعداداته العامة الحالية فقط.
